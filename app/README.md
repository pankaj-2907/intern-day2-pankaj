# AI Text Intelligence Service

A modular, production-ready FastAPI service powered by the latest Google Gemini SDK (`google-genai`). It provides asynchronous/synchronous text processing endpoints for Summarization, Classification, and Sentiment Analysis.

---

## Project Architecture (Clean Architecture)

The project follows a clean, modular directory structure to ensure maintainability, scalability, and separation of concerns:

```plaintext
Task_day2/
│
├── app/
│   ├── main.py              # Application entry point & FastAPI setup
│   ├── routes/
│   │   └── ai.py            # API routing & endpoint handlers
│   ├── schemas/
│   │   └── ai_schemas.py    # Pydantic request & response validation models
│   └── services/
│       └── llm_service.py   # Business logic & Google GenAI SDK integration
│
├── venv/                    # Python Virtual Environment
├── .env                     # Environment variables (API Keys)
└── README.md                # Project Documentation
```

## Tech Stack & Tools

* **Framework:** FastAPI
* **Server:** Uvicorn (ASGI)
* **Validation:** Pydantic v2
* **AI Engine:** Google Gemini SDK (`google-genai`)
* **Environment Management:** python-dotenv
* **Language:** Python 3.12+

Install the required packages using pip:
```powershell

```

### 4. Configure Environment Variables
Create a `.env` file in the root directory and add your Google Gemini API key:
```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
```

## 🔌 API Endpoints & Usage

### 1. Root Check
* **URL:** `GET /`
* **Description:** Welcomes users and points to documentation.

### 2. Text Summarization
* **URL:** `POST /ai/summarize`
* **Request Body (JSON):**
```json
{
  "text": "Your long text to be summarized goes here..."
}
```
* **Response:**
```json
{
  "summary": "Concise summary generated by Gemini."
}
```

### 3. Text Classification
* **URL:** `POST /ai/classify`
* **Request Body (JSON):**
```json
{
  "text": "FastAPI and Python make building scalable web APIs extremely efficient."
}
```
* **Response:**
```json
{
  "category": "Technical",
  "confidence": 0.95,
  "reasoning": "The text discusses software development tools and frameworks."
}
```

### 4. Sentiment Analysis
* **URL:** `POST /ai/sentiment`
* **Request Body (JSON):**
```json
{
  "text": "I am so happy with how fast and smooth this API performs!"
}
```
* **Response:**
```json
{
  "sentiment": "Positive",
  "score": 0.9,
  "explanation": "The user expresses high satisfaction and excitement about the API performance."
}
```

## Design Decisions & Best Practices

* **Strict Schema Separation:** Uses distinct Pydantic models for request validation and response formatting, ensuring clean Swagger documentation and robust type-checking.
* **Modern SDK Migration:** Fully migrated from the legacy `google-generativeai` library to the latest `google-genai` client standard.
* **Modular Service Layer:** Decoupled business and AI logic (`llm_service.py`) from HTTP handling (`routes/ai.py`), making it straightforward to swap AI providers or add features in the future.
