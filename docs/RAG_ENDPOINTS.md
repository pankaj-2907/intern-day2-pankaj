# Task 6: FastAPI RAG Endpoints Documentation

This document outlines the API design, schemas, routes, and error handling for the RAG Question-Answering system built using FastAPI.

---

## 1. Overview of Endpoints

| Endpoint | Method | Description | Response Model |
| :--- | :--- | :--- | :--- |
| `/rag/ask` | `POST` | Accepts a natural language question and top-K parameter, retrieves chunks, and returns a grounded LLM answer with source citations. | `AskResponse` |
| `/rag/health` | `GET` | Verifies system readiness and ensures the vector index is loaded. | `HealthResponse` |
| `/rag/sources` | `GET` | Returns a list of all available source documents in the knowledge base. | `SourcesListResponse` |

---

## 2. Pydantic Request & Response Schemas (`app/schemas/rag_schemas.py`)

### `AskRequest`
* **`question`** (`string`, required): The natural language query to ask the RAG system (min length: 1).
* **`top_k`** (`integer`, optional): Number of top relevant chunks to retrieve (default: `3`, range: `1` to `10`).

### `AskResponse`
* **`question`** (`string`): The original question asked by the user.
* **`answer`** (`string`): The grounded answer generated by Gemini LLM based strictly on the retrieved context.
* **`sources`** (`array` of objects): List of source documents referenced in the answer.
  * `document_id`: Unique identifier of the source document (e.g., `doc_001`).
  * `title`: Title of the source document.
  * `chunk_id`: Specific chunk identifier used.
* **`retrieved_chunks`** (`integer`): Total number of chunks successfully retrieved and utilized.

## 3. API Route Details & Error Handling (`app/routes/rag.py`)

### A. `POST /rag/ask`
* **Function:** Executes retrieval + prompt construction + Gemini generation.
* **Status Codes:**
  * `200 OK`: Successful answer generation.
  * `422 Unprocessable Entity`: Validation failure (empty question or invalid `top_k`).
  * `503 Service Unavailable`: Retrieval provider failure or LLM API error.
  * `500 Internal Server Error`: Unexpected runtime errors.

**Example Request:**
```json
{
  "question": "How can an API be protected against unauthorized access?",
  "top_k": 3
}
```

**Example Response:**
```json
{
  "question": "How can an API be protected against unauthorized access?",
  "answer": "Based on the provided documents, an API can be protected through authentication using OAuth2, role-based authorization, and strict input validation.",
  "sources": [
    {
      "document_id": "doc_001",
      "title": "API Security Best Practices",
      "chunk_id": "doc_001_chunk_001"
    }
  ],
  "retrieved_chunks": 1
}
```

### B. `GET /rag/health`
* **Function:** Confirms that the retrieval service has successfully initialized and populated its vector index.
* **Status Codes:**
  * `200 OK`: `{"status": "ok"}`
  * `503 Service Unavailable`: Index is empty or uninitialized.

### C. `GET /rag/sources`
* **Function:** Reads `data/documents.json` and returns all available source metadata items (IDs and titles) without exposing raw embeddings.
* **Status Codes:**
  * `200 OK`: Returns list of source items.
  * `500 Internal Server Error`: File read failure.
