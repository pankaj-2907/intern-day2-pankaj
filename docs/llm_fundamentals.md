# 🧠 LLM Fundamentals & Core Concepts

---

## 1. What is a Large Language Model (LLM)?
* **Explanation:** An LLM is an advanced AI model trained on massive amounts of text data to understand human language and generate natural responses. It predicts the most likely next words based on contextual patterns learned during training.
* **Example:** Similar to how a smartphone keyboard predicts your next word while texting, an LLM predicts entire sentences or paragraphs based on context (e.g., Google Gemini).

## 2. How is an LLM different from traditional rule-based software?
* **Explanation:** Traditional software relies on rigid, deterministic `if-else` rules written by developers. LLMs operate on probabilistic patterns and meaning, allowing them to handle ambiguity, adapt to conversational shifts, and understand nuance.
* **Example:** 
  * *Traditional Software:* A chatbot that only replies if a user types the exact string `"hello"`.
  * *LLM:* A chatbot that understands `"Hi"`, `"Hey there"`, or `"Arre hello!"` and responds naturally.

## 3. What are tokens?
* **Explanation:** LLMs do not process words directly; they break text into smaller chunks called tokens. A token can be a part of a word, a whole word, or punctuation (roughly 1 token $\approx$ 0.75 words in English).
* **Example:** The word `"Artificial"` might be split into tokens like `Arti` and `ficial`.

## 4. What is a context window?
* **Explanation:** The context window defines the maximum number of tokens (input plus output combined) a model can process and retain in its active memory during a single interaction.
* **Example:** If a model has an 8,000-token context window, you can feed it a medium-length article, but not an entire multi-volume book at once.

## 5. What is a prompt?
* **Explanation:** A prompt is the instruction, question, or input text provided to an LLM to guide its behavior and generate the desired output.
* **Example:** `"Summarize the following technical article in 3 bullet points: [Article text]"`

## 6. What are system, user, and assistant messages?
* **Explanation:** Roles used in LLM API conversations to structure dialogue:
  * **System:** Sets the persona, rules, and boundaries for the model.
  * **User:** The actual query or command given by the user.
  * **Assistant:** The response generated by the model.
* **Example:** System says *"You are a helpful coding assistant"*, User says *"Fix this bug"*, and Assistant provides the solution.

## 7. What is inference?
* **Explanation:** Inference is the runtime process where a trained model takes an input prompt and generates a response. It differs from training, which is the heavy computational phase where the model learns patterns.
* **Example:** When your FastAPI backend calls the Gemini API and receives a summarized text back, that execution is inference.

## 8. What is temperature?
* **Explanation:** A hyperparameter that controls the randomness and creativity of the model's output. Low temperature ($0.0$) yields deterministic, factual answers; high temperature ($>1.0$) yields creative, varied answers.
* **Example:** Setting temperature to $0.1$ for debugging code vs. $0.9$ for writing creative poetry.

## 9. What is a hallucination?
* **Explanation:** When an LLM generates factually incorrect, fabricated, or imaginary information with high confidence because it predicts statistically plausible text rather than verifying objective truth.
* **Example:** Asking an LLM about a fictional historical event and receiving a detailed, completely made-up story presented as fact.

## 10. What is structured output?
* **Explanation:** Constraining or instructing the LLM to return its response in a predictable, machine-readable format (such as JSON) rather than free-form text.
* **Example:** Expecting a JSON response like `{ "category": "technical", "confidence": 0.95 }`.

## 11. What is the difference between an LLM and an LLM API?
* **Explanation:** 
  * **LLM:** The underlying core neural network model weights and architecture.
  * **LLM API:** A cloud-hosted service wrapper that provides secure, remote access to the LLM over the internet.
* **Example:** The LLM is like a powerful engine, while the LLM API is the dashboard and steering mechanism you use to drive it.

## 12. What is the difference between an LLM API call and a normal REST API call?
* **Explanation:** 
  * **Normal REST API:** Deterministic, fast, and yields the exact same database/backend result for a given request.
  * **LLM API:** Probabilistic, slower (due to token generation), and can produce slightly varied outputs for identical inputs.
* **Example:** Fetching a user profile via REST API vs. asking an LLM to rewrite a bio.

## 13. Why can the same prompt produce different responses?
* **Explanation:** Because LLMs sample tokens probabilistically based on probability distributions and temperature settings, rather than returning hardcoded outputs.
* **Example:** Running the same classification prompt twice might yield slightly different reasoning text even if the category is correct.

## 14. What happens when an input exceeds the model's context limit?
* **Explanation:** The API typically throws a validation error, or the underlying system truncates/drops older parts of the input text, leading to a loss of context.
* **Example:** Passing a 50-page report to a model with a small context limit results in missing information from the beginning or end.

## 15. Why should LLM output be treated as untrusted input?
* **Explanation:** Because LLMs can hallucinate, return malformed data, or be vulnerable to prompt injection attacks where malicious input alters model behavior. Backend code must always validate and sanitize LLM outputs.
* **Example:** Executing raw code or database queries generated directly by an LLM without validation can compromise security.
